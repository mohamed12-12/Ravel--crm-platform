# Demo Web Layer

This folder contains the spreadsheet demo web surface.

- `templates/` contains the customer chat and CRM demo pages.
- `static/` contains browser JavaScript and CSS.
- `auth.py` contains the current demo-only CRM login guard.
- `api_routes.py` exposes `/api/v1/*` routes used by the demo CRM UI.

The authentication here is for MVP/demo use only and must be replaced before production.
