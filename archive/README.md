# Archive

This archive stores historical MVP material that may still be useful for context but should not be treated as current runtime documentation.

- `mvp-phase-artifacts/` contains phase reports and usage notes from the spreadsheet-first MVP.
- `deprecated-env/` contains superseded environment templates retained for review instead of being deleted.
- `legacy_demo_web/` contains the retired standalone demo wrapper.
- `source-artifacts/` contains local PDFs, spreadsheet snapshots, and resolved planning notes retained for manual review.
