# Target Repository Structure

```text
apps/       # CRM, agent demo, admin web, middleware
services/   # crm, ai_agent, instagram, notifications
database/   # migrations, schema, seeds
scripts/    # development, maintenance, migration, testing
tests/      # unit, integration, api, ai_agent, regression, fixtures
docs/       # architecture, business, api, ai-agent, testing, operations,
            # security, audits, plans, reports, archive
archive/    # legacy-demo, manual-review, mvp phases, source artifacts
```

No move is approved. Each move requires import, configuration, deployment and test impact review.
