# Manual Test Checklist

- Use isolated demo DB/workbook; verify CRM and agent health.
- Test Arabic, English, mixed language, identity before/after trip intent, existing/new/duplicate/blocked/pending/VIP travelers.
- Verify local fallback, international availability, room gender inventory, group size and flight choice one question at a time.
- Verify lead fields match chat facts; draft only after requirements are met.
- Verify passport upload type, size, access and lead/traveler linkage.
- Verify cancellation, duplicate booking, sold-out inventory, human request, complaint, payment, tool/Gemini failure, reset and session expiry.
- Verify portal snapshot, CRM UI and persisted records agree after each write.
