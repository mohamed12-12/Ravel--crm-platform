## Summary

This pass did not change business logic. It only removed generated artifacts and moved uncertain local/manual-review material out of runtime paths.

## Deleted Files And Folders

Deleted generated artifacts only:

- Python bytecode caches: all `__pycache__/` folders outside `node_modules`.
- Pytest cache: `.pytest_cache/`.
- Temporary test work directories: `.tmp-test-workdirs/`.
- Frontend build output: `apps/admin-web/dist/`.
- Middleware TypeScript build output: `apps/middleware/dist/`.

Why removed:

- These are generated by Python, pytest, Vite, and TypeScript.
- They are reproducible with `npm run build` and test commands.
- They are ignored or should be ignored in production source control.
