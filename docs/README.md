# Rahma Travel OS Documentation

This folder is the working documentation home for Rahma Traveler / Rahma Travel OS.

- [Architecture overview](./architecture.md) explains the current MVP layers and production direction.
- [Folder structure](./folder-structure.md) describes what belongs where.
- [Setup](./SETUP.md) covers local installation and development commands.
- [Instagram / Meta integration notes](./instagram-integration-plan.md) captures the future webhook and messaging work.
- [Production readiness checklist](./production-checklist.md) tracks the remaining hardening work.
- [Cleanup report](./08_reports/PROJECT_CLEANUP_REPORT.md) records the latest repository cleanup pass.

Historical phase plans live under [plans](./plans/README.md). Archived MVP artifacts live in the root [archive](../archive/README.md).

Structured documentation folders:

- `00_status/` - current state and approved status snapshots.
- `01_architecture/` - product, data model, and redesign decisions.
- `02_workflows/` - approved traveler, CRM, and booking workflows.
- `03_crm/` - CRM-specific analysis and contracts.
- `04_agent/` - AI agent workflow analysis and behavior notes.
- `05_migration/` - migration audits, recovery analysis, and promotion reports.
- `06_testing/` - QA, validation, and test-focused reports.
- `07_client/` - client-facing requirement and release notes.
- `08_reports/` - implementation and cleanup reporting.
- `09_archive/` - historical plans retained for context.
