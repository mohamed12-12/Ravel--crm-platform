# Contributing

Thanks for helping improve Rahma Travel OS.

## Guidelines

- Keep business logic intact unless a change is explicitly requested.
- Prefer small, reviewable changes.
- Add or update tests for behavior changes.
- Do not commit secrets or generated artifacts.
- Keep docs and workflows aligned with code changes.

## Local Development

1. Install dependencies with `npm install`.
2. Install Python requirements with `python -m pip install -r rahma-traveler/requirements.txt`.
3. Run tests with `npm test`.
4. Build with `npm run build`.

## Pull Requests

- Explain the user-facing change.
- Call out any migration or environment requirements.
- Note any follow-up work that is intentionally deferred.
